# 子代理领域研究汇总资料

本文档保存了6个领域研究子代理返回的全部原始深度研究数据，以供后续迭代与查阅调用。

## 1. 经济学、市场动态与资源系统
- **微观经济学**：供需法则、效用理论。NPC不直接计算方程，底层计算效用得分Top3给LLM决策。
- **行为经济学**：前景理论、损失厌恶、禀赋效应。通过Prompt注入“非常看重某物”自然产生偏见。
- **市场机制**：连续双向竞价（底层逻辑）+ 纳什双边议价（LLM自然语言交涉）。
- **ACE（基于代理的计算经济学）**：宏观-微观混合架构（LOD）。90%底层NPC纯代码驱动，10%核心LLM驱动。
- **资源与生产**：严格分离决策层与物理层。遵循物理守恒，防LLM凭空捏造。
- **货币理论**：宏观调控守门员Agent，监控M0/M1，调节税率防止恶性通胀。
- **劳动经济学**：结合市场需求与自身天赋决定转行成本与意愿。
- **制度经济学**：信誉积分与违约惩罚，NPC可通过自然语言签订契约并由系统监督。
- **生态与可持续**：资源耗竭反馈循环（树木砍伐->木材涨价->买不起柴火->效用下降）。
- **LLM经济学前沿**：Homo Silicus，符号接地限制。强制JSON输出决策并由系统校验预算。

## 2. 心理学与人格建模
- **大五人格 (OCEAN)**：连续维度超参数，控制记忆过滤与社交主动性。
- **MBTI**：构建角色原型与分工，易受社会赞许性偏差影响。
- **黑暗三角**：马基雅维利主义、自恋、精神病态。设计反派，需注意LLM RLHF对齐带来的“谄媚”限制。
- **荣格原型**：英雄之旅叙事阶段。
- **弗洛伊德潜意识**：本我（功利）、超我（道德）、自我（调停）的多智能体Debate架构。
- **马斯洛需求**：与效用AI结合，低层级安全需求未满足时中断高层社交对话。
- **情感模型 (OCC/PAD/Plutchik)**：OCC解析事件，更新PAD连续情绪向量，映射到Plutchik情感轮输出语气。
- **依恋理论**：控制NPC长期羁绊逻辑（分离焦虑 vs 疏离回避）。
- **图式理论 (Schema)**：认知偏差/偏见滤镜，如被害妄想图式误解中立动作。
- **特质激活理论 (TAT)**：特定环境线索触发隐藏人格特质。

## 3. 社会学与群体动力学
- **社会网络理论**：邓巴数优化Context加载（5/15/50/150层级）。弱连接跨区域传播信息。
- **社会交换理论**：成本收益与互惠规范。任务接取算分 `Reward - Cost + 欠人情指数`。
- **结构功能主义**：系统平衡与自我修复（铁匠死亡，学徒自动接替）。
- **冲突理论**：阶级资源不平等积累引发罢工/游行（宏观事件生成）。
- **符号互动论（镜中我）**：依据外界评价动态更新Persona（Reflection修正）。
- **社会认同理论**：内外群体偏差（Tag标签匹配），决定初始好感与价格歧视。
- **集体行为**：谣言的传染病模型（SIR），结合NPC判断力产生信息变异。
- **社会资本**：桥接资本与粘合资本。乞丐也能成为情报网络核心。
- **博弈论**：基于分布式声誉系统的迭代合作与背叛。
- **规范形成**：违规可见度与分级惩罚体系，自下而上涌现村规。

## 4. 世界模型架构、物理与环境
- **AI世界模型**：NPC内部含有迷你世界预测模型（Latent Space规划），实现真正的Zero-shot。
- **ECS架构**：Data-Oriented，实体-组件-系统。完美适配大规模NPC并发，LLM作为异步系统挂载。
- **空间与时间**：事件演算，赋予NPC“时间感知”与作息（Routine）。
- **因果推理与Event Sourcing**：CQRS架构，世界状态由严格因果事件流叠加，方便LLM侦探推理。
- **社交物理学**：近空间学（Proxemics）与空间句法，决定NPC站位与自然相遇概率。
- **PCG生成**：波函数坍缩（WFC）结合LLM语义控制生成村落。
- **CRDT与持久化**：快照+日志，保障万级Tick演进的分布式一致性。
- **仿真扩展性（AI LOD）**：兴趣管理与薛定谔的NPC，视距外降级为统计模型，视距内坍缩为LLM Prompt。

## 5. LLM认知架构与记忆系统
- **经典认知**：ACT-R/Soar/LIDA 映射为 LLM混合架构（LLM为工作区，向量库为长期记忆，工具为程序记忆）。
- **智能体框架**：借鉴AgentVerse/CAMEL，NPC后台隐形组队协作（如密谋）。
- **推理范式**：日常闲聊直出，生死攸关切换至ToT/GoT+Reflexion进行深思与反思。
- **记忆架构**：MemGPT分页调度。Generative Agents观察-检索-反思-计划流。引入Ebbinghaus遗忘曲线节约Token。
- **多智能体通信**：广播、私聊、基于距离的“窃听”，形成信息隔离机制。
- **规划执行**：LLM + GOAP/HTN 混合。LLM定战略目标，底层GOAP寻路执行防穿模。
- **符号接地**：Affordance（可供性）约束，Prompt注入当前物理允许的Action List。
- **心智理论 (ToM)**：递归信念建模，实现欺骗与反转。
- **Token优化**：System 1 (本地小模型处理日常) + System 2 (云端大模型处理关键剧情)，语义缓存，按需唤醒。

## 6. 叙事设计与游戏AI
- **Drama Manager**：宏观导演LLM，监控世界张力值，动态注入事件。
- **程序化叙事**：Ink/Twine作为主线骨架约束，LLM在分支节点进行涌现式填充。
- **游戏AI前沿**：抛弃LLM直接微操。LLM修改“效用函数权重”，底层Utility AI/HTN接管。
- **Nemesis System（复仇女神）**：RAG检索过往恩怨，LLM根据交恶历史生成复仇宣言与派系演化。
- **Sims 架构**：智能对象（Smart Objects）广播Affordance，NPC无需懂怎么看电视，而是电视告诉NPC“我能提供娱乐”。
- **Dwarf Fortress涌现**：情绪螺旋（Tantrum Spirals），微小个体悲伤引发群体灾难崩溃。
- **对话系统**：意图识别 + 隐形对话树推进任务状态，结合LLM自由回答。
- **Lore一致性**：GraphRAG（知识图谱检索增强），防幻觉，设定专门的审校LLM。
- **共情设计**：NPC需输出内部独白（Inner Monologue）指导引擎渲染细微表情动画。
